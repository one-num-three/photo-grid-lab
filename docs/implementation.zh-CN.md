# 实现说明

[English](implementation.md)

## 文件和运行结构

展示网站使用原生 HTML、CSS 和 JavaScript，通过同源 iframe 嵌入独立演示。语言切换会带着明确的语言参数重载 iframe，因此会重置当前演示位置。

照片区域使用 Canvas 2D，标题、滑块、按钮和可访问性播报使用 DOM。照片以内嵌 data URL 加载。修改 `demo/source.html` 后，使用 `tools/build-demo.py` 将缓存照片写入模板，生成 `demo/index.html`。

## 布局与焦点保持

缩放值 `z` 的范围是 0 到 4，对应每行 `[1, 3, 5, 9, 13]` 张。小数值表示相邻档位之间的过渡。单列布局保留照片长宽比，并把高宽比限制在 0.66 到 1.3；多列布局使用方形裁切。

手势开始时，`makeAnchor` 记录指向的照片、手指在照片内的相对位置和手势中心。`applyZoom` 计算新几何位置后补偿横向偏移和纵向滚动，让同一个点尽量留在手势中心。内容首尾需要限制滚动，因此无法对所有边界照片保持绝对固定。

各档位的起始填充用于把焦点安排到合适的列，这是布局状态，不是额外照片。

## 网格过渡

最初逐张移动照片的方案会在中间帧露出空隙，最终改为围绕同一焦点绘制两层完整网格，并用 `t²(3−2t)` 控制交叉过渡。焦点照片最后单独绘制，保持不透明。

稳定布局只绘制视口和附近区域，单列定位使用累计高度与二分查找。Canvas 的设备像素比上限为 2。当前过渡中仍可能出现轻微叠影；这是一种网页实现方案，不代表苹果的内部算法。

## 主要参数

| 参数 | 当前值 |
| --- | --- |
| 列数档位 | 1、3、5、9、13 |
| 普通及密集间距 | 1.7 及 1 CSS 像素 |
| 捏合灵敏度 | 双指距离比的对数乘以 1.35 |
| 按钮及释放动画 | 约 440 及 380 毫秒 |
| 演示过渡及停顿 | 约 760 及 400 毫秒 |
| 滚轮单次幅度限制 | 缩放前限制为 ±120 |
| 滚轮释放判定 | 160 毫秒 |
| 惯性初速度限制 | ±3600 CSS 像素每秒 |
| 范围内速度衰减 | exp(−5.2 × dt) |
| 模拟数据 | 864 条记录、28 张照片 |

动画打断、反向操作和滚动共用取消处理。滚动打断中间缩放时，会先恢复稳定档位并补偿焦点纵向位置。Pointer capture 保持输入归属，Safari gesture 事件用于补充 Pointer 和滚轮路径。

## 可访问性和边界

控件具备可访问名称、键盘操作和密度播报。减少动态效果模式缩短动画，并抑制正常惯性甩动。Canvas 内每张照片暂未独立提供屏幕阅读器访问。

当前提前载入少量重复照片。真实资料库还需要稳定资料 ID、异步缩略图、缓存、失败状态、持久化排序及规模验证。`window.photoGrid.state` 仅提供只读诊断；其中 `drawMs` 只统计绘制函数，不能据此宣称稳定帧率。

日期和资料顺序均为模拟值。初始滚动位置位于内容中段，便于减少首尾边界对演示的影响。

## 视频

MP4 录制自实际 Chromium 操作，包含自动演示、模拟触摸拖动、惯性滚动和按钮缩放。浏览器录制视口为 540 × 1170 CSS 像素。最终无声 H.264 MP4 缩放导出为 1080 × 2340，并使用浏览器友好的像素格式和 fast-start 元数据；导出分辨率不表示原始录制具有原生 1080 像素细节。GIF 是同一录屏的精简预览。

网页另外使用 720 × 1560 的精简 MP4，下载入口保留 1080 × 2340 的导出版本。两者均为同一段实际录屏。
