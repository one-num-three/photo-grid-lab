## 中文简介

用 HTML、Canvas 和原生 JavaScript 做了一个受苹果相册启发的照片网格：连续捏合缩放、焦点照片保持、密集照片墙、惯性滚动和柔和吸附。

视频录制的是实际运行的网页原型，照片都是模拟资料。它还不是原生 App，真实设备体验也欢迎大家一起反馈。

## English description

A small, handcrafted photo-grid experiment in HTML, Canvas and vanilla JavaScript: continuous pinch-to-zoom, an anchored photograph, dense mosaics, inertia and gentle snapping.

This clip records the actual web prototype with mock photos. It is not a native app. Try it, inspect the implementation, or help improve the gesture edge cases.

Live playground: https://one-num-three.github.io/photo-grid-lab/

Source: https://github.com/one-num-three/photo-grid-lab

If it sparks an idea, a star helps others find it. Issues and PRs are welcome.
